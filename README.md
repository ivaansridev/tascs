# tascs

A tiny task app built with Compose Multiplatform for Android and desktop.

## Features

- Dark Material 3 theme with a yellow palette
- Centered **Tascs** top app bar
- Bottom navigation bar: **All tasks** and **Lists**
- Plain task rows with an optional subtitle and due date
- Swipe a row to the left to delete it (tasks and lists)
- FAB with **+**: adds a task on *All tasks*, a list on *Lists*
- Due dates via the Material date picker, with "Due today", "Due tomorrow", and "Overdue" labels
- Tapping a list filters *All tasks*; **Show all** clears the filter
